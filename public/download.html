Setup & Installation

Install the Browser Extension

Get the complete Manifest V3 companion extension loaded in Chromium browsers in less than 30 seconds.

Ephemeral Secret Vault — Extension Package (.ZIP)

Pre-packaged Manifest V3 extension ready for Developer Mode installation in Chrome, Edge, Brave, and Opera.

Download Extension (.ZIP) Use Web App Instead
1

Download and Extract Archive

Download the ZIP package above and extract it into a folder on your computer. If you cloned the repository, the extension files are already in the extension/ directory.

2

Open Browser Extensions Page

Paste the appropriate management URL into your browser address bar:

chrome://extensions (Google Chrome & Brave)
edge://extensions (Microsoft Edge)
3

Enable "Developer mode"

In the top-right corner of the Extensions page, toggle the switch labeled Developer mode to the ON position.

4

Click "Load unpacked" and Select Folder

Click the button labeled Load unpacked in the top-left toolbar, browse to the folder where you extracted the extension, and click Select Folder.
