Installation Guide
1
Download the ZIP Archive
Click the download button above to save ephemeral-secret-vault-extension.zip to your computer.
2
Open Extensions Manager
Navigate to chrome://extensions in Chrome, Edge, or Brave. Enable Developer Mode using the toggle in the top-right corner.
3
Load Unpacked Extension
Unzip the archive, then click "Load unpacked" and select the unzipped extension folder.
4
Pin & Start Vaulting
Pin the Ephemeral Vault icon to your toolbar. Visit Gmail, Slack, or WhatsApp and look for the vault icon to start protecting secrets.
Security Transparency The extension is fully open-source. It only uses the permissions it needs: activeTab, contextMenus, storage, and scripting. No data is transmitted to third parties. All secrets are encrypted client-side before reaching the vault server.
