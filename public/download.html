Installation Guide
01
Download and Extract the ZIP
Click the download button above. Save the file, then extract the ZIP archive to a folder you can find easily (e.g., Desktop).
02
Open Extensions Manager
In Chrome/Edge/Brave, open the extensions page and enable Developer Mode using the toggle in the top-right corner.
chrome://extensions
03
Load the Extension Folder
Click "Load unpacked" and select the extracted extension folder. The Ephemeral Vault icon will appear in your toolbar immediately.
04
Pin to Toolbar & Start Sharing
Click the extensions puzzle icon and pin "Ephemeral Secret Vault" for quick access. Open WhatsApp Web or Gmail and click the toolbar icon to share secrets.
Privacy Guarantee
The extension requires no external permissions beyond the domains you visit. It never reads, stores, or transmits your secrets or browsing history. The extension only creates vault links through the Ephemeral Secret Vault API you already trust.
