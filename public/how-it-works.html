Cryptographic Lifecycle

How Ephemeral Works

From browser-side encryption to physical server deletion — your secret never travels in the open.

01
Create

Draft Your Secret

Paste confidential notes, credentials, API keys, certificates, or upload a file. The creation interface supports text up to 10 KB and files up to 15 MB.

Auto-detectionClassifies API keys, passwords, certificates, JWTs automatically
02
Encrypt

AES-256-GCM in Your Browser

With Zero-Knowledge mode enabled, your browser uses the Web Crypto API to generate a 256-bit key and encrypt the secret locally. The server receives only ciphertext — the plaintext and key never leave your device.

Algorithm
AES-256-GCM
IV Length
96-bit random
Auth Tag
128-bit GCM
Key Location
URL hash only
03
Share

Send via Any Platform

A random, non-enumerable 128-bit vault link is generated. Share it via WhatsApp, Gmail, Slack, Discord, Teams, or Telegram. The link itself contains no secret data — only an encrypted pointer.

https://vault.domain/v/a8f9c1e2b3d4…#key=bX3kP9mQ…
04
Authorize

Two-Step Backend Authorization

The backend validates the request context, checks for bot/crawler traffic (preventing accidental preview burns), and issues a single-use reveal token. The recipient must submit both the token and optional passphrase to proceed.

Two-Step Flow
1
POST /api/vault/:id/reveal/request → returns token
2
POST /api/vault/:id/reveal + token → ciphertext
05
Reveal & Shred

Atomic Decrypt & Permanent Purge

The ciphertext is returned to the browser, decrypted in RAM using the key from the URL hash, and displayed. Simultaneously, the SQLite record is atomically decremented — if views reach zero, the row is hard-deleted and WAL-checkpointed in the same transaction.

UPDATE secrets SET views_remaining = views_remaining - 1 WHERE id = ? RETURNING ...
DELETE FROM secrets WHERE id = ? -- if views_remaining = 0
Technology Stack

Built for Security

AES-256-GCM

NIST SP 800-38D

Authenticated encryption with 96-bit IV and 128-bit integrity tag. Tamper detection built-in.

SQLite WAL

secure_delete = ON

Write-Ahead Log with PRAGMA secure_delete ensures zero residual ciphertext on disk after purge.

Web Crypto API

SubtleCrypto.encrypt()

Browser-native cryptography. Key generation, encryption, and decryption never touch the server.

PBKDF2 / bcrypt

Key stretching

Optional passphrase protection uses PBKDF2 key-stretching with a random salt to resist brute-force.

Bot Guard

Preview crawler detection

Detects and blocks WhatsApp, Slack, Discord link-preview crawlers to prevent accidental burns.

Rate Limiting

30 create / 60 reveal per min

Per-IP rate limits on creation and reveal endpoints prevent automated scraping or flooding.
