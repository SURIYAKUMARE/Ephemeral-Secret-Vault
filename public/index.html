CRYPTOGRAPHIC ARCHITECTURE

Built with True Ephemeral Guarantees

Designed from first principles to withstand curious recipients, link-crawling bots, and server inspection attacks.

AES-256-GCM Encryption

Authenticated 256-bit encryption with random 96-bit IVs and 128-bit authentication tags prevents ciphertext tampering.

Two-Step Reveal Flow

Vault IDs are non-sensitive locators. Plaintext is only unlocked when an authorized human requests a single-use reveal token.

Link Preview Defense

Slackbot, Discordbot, Twitterbot, and WhatsApp link unfurlers receive a static dummy shell and cannot trigger a secret burn.

Memory Zeroization

In-memory decrypted buffers are filled with cryptographically random zeros immediately following transmission.

Active TTL Sweeper

A background engine periodically purges expired secrets from SQLite storage even if the recipient never opens the link.

Passphrase Brute Defense

Incorrect passphrase attempts trigger exponential backoffs. 3 consecutive failed guesses triggers automatic destruction.

FAQ

Frequently Asked Questions

Everything you need to know about secure ephemeral secret sharing.

What happens when I share a vault link via WhatsApp or Slack? ▼
Only the random vault link is sent. The actual secret text or file is never transmitted across the chat platform. Chat bots that expand links receive a static shell and cannot reveal or burn the secret.
Can an expired or burned secret ever be recovered? ▼
No. When a secret expires or reaches its maximum view limit, the database row is physically purged and in-memory buffers are wiped with zeros. Recovery is mathematically impossible.
Is the secret visible in the initial page source or HTML? ▼
No. The secret is never embedded in HTML, JavaScript variables, CSS, Base64 strings, or cookies. It can only be delivered over TLS after an authorized human clicks "Reveal Secret".
What file types and sizes are supported? ▼
You can share confidential scripts (Python, Bash, JS), configuration files (.env, JSON, YAML), certificates (.pem, .key), documents (.pdf), and images (.png, .jpg) up to 10 MB.
How does the browser extension work? ▼
The extension adds a quick "Paste & Secure" command (Ctrl+Shift+V) and context menu in WhatsApp Web, Gmail, Outlook, Slack, and Discord. It encrypts the secret and injects only the safe link into your message draft.
