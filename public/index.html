HOW IT WORKS

Cryptographic Lifecycle

From browser encryption to physical server deletion, the secret never travels in the open.

STEP 01

Create

Draft your confidential note or upload credentials, tokens, or scripts.

STEP 02

Encrypt

AES-256-GCM generates a random 96-bit IV and authenticated ciphertext tag.

STEP 03

Share Link

Dispatch the single-use random link through WhatsApp, Slack, Teams, or email.

STEP 04

Authorize

Recipient opens link; backend validates context and issues a single-use reveal token.

STEP 05

Reveal / Shred

Decrypted in browser RAM; database row is physically purged immediately.

ENTERPRISE SECURITY

Engineered for High-Trust Teams

Every feature is architected with defense-in-depth principles to protect your sensitive payloads.

Secure Links

Cryptographically random, non-enumerable 128-bit pointers that never reveal secrets in URLs or server access logs.

Encrypted Vaults

Authenticated AES-256-GCM ciphertexts with 128-bit integrity tags guaranteeing tamper-evident storage.

Auto Expiration

Automated background sweepers purge records upon TTL expiration, guaranteeing zero long-term data retention.

One-Time Access

Single-use cryptographic shredding purges database rows the millisecond the recipient's reveal completes.

View Limits

Granular allowance counts (1, 3, 5, 10, or custom limits) decrementing atomically within strict SQLite transactions.

Passcode Protection

Optional PBKDF2 key-stretching defense requiring a secondary passphrase before authorized decryption.

Secure Sharing

Direct deep links for WhatsApp, Slack, Teams, Discord, Gmail, and Outlook that share strictly the vault pointer.

Browser Extension

Manifest V3 companion for instant vault creation from any active tab without opening the full web application.

Secure Clipboard

Explicit-action clipboard ingestion that previews content and never continuously or silently polls your device.

File Protection

Encrypted binary storage for certificates, scripts, PDFs, and keys up to 15 MB with automatic MIME isolation.

Creator Controls

Local metadata tracking with manual emergency burn capabilities that permanently shred links on demand.

Audit Events

Tamper-evident verification receipts and zero-plaintext access tracking for security compliance reviews.
