How It Works

1. Create: Input confidential credentials. Encrypted in memory with AES-256-GCM.

2. Share: Transmit the random vault link. Plaintext never enters chat messages.

3. Burn: Recipient reveals once with a single-use token. Database row is permanently purged.

Security Architecture

Authenticated Encryption: Protected with 256-bit AES-GCM and 128-bit authentication tags.

Zero Plaintext Storage: Plaintext never touches disk unencrypted. Memory buffers are zeroized upon transmission.

Frequently Asked Questions

Can a burned secret be recovered? No. Once burned, storage is physically wiped. Recovery is mathematically impossible.

What is Portable HTML? An offline decryptor capsule that decrypts entirely client-side in the recipient's browser.
