IN-BROWSER WORKFLOW

Zero Plaintext in Message Drafts

01 • Write or Paste
Open any chat message in WhatsApp, Gmail, or Slack. Press Ctrl+Shift+V or right-click to trigger the vault modal.
02 • Smart Detection
The extension automatically recognizes API tokens, AWS keys, JWTs, and passwords, suggesting instant protection.
03 • In-Memory Encryption
The payload is encrypted before transmission. If offline, the extension falls back to client-side Web Crypto AES-256-GCM.
04 • Safe Link Replaced
The chat input is safely replaced with an auto-expiring single-use link. Recipient opens link to decrypt and self-destruct.

Extension Security Architecture

Isolated Shadow DOM
Extension injection renders strictly inside an Isolated Shadow DOM. Host pages (e.g., Slack or WhatsApp scripts) cannot read, inspect, or intercept the passphrase input.
Zero Persistent Secrets
The extension service worker zeroizes all payload references after transmission. No plaintexts or decrypted blobs are retained in extension storage.
