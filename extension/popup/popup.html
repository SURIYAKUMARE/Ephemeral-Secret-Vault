🔐 Zero-Trace Architecture

Ephemeral Secret Vault never stores plaintext secrets, encryption keys, or authentication tokens in extension storage or browser history.

  • Zero Plaintext Storage: Secrets are encrypted at rest via AES-256-GCM.
  • Atomic Self-Destruction: The secret is purged from the database immediately upon view or expiry.
  • Anti-Leak Headers: Response headers prevent browser and proxy caching.
  • Bot Guard: Link preview crawlers (WhatsApp, Slack, Discord) never trigger premature burns.
