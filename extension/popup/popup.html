🔐 Zero-Trace Vault Architecture

Ephemeral Secret Vault never stores plaintext secrets, encryption keys, or authentication tokens in extension storage or browser history.

  • Zero Plaintext Storage: Secrets are encrypted at rest with authenticated AES-256-GCM.
  • Atomic Self-Destruction: The secret is purged from the database immediately upon view or expiry.
  • Bot & Crawler Defense: Link preview crawlers (WhatsApp, Slack, Discord) never trigger premature burns.
  • Passphrase Protection: Optional PBKDF2/Argon2 passphrase-gated decryption with brute-force defense.
  • Offline Zero-Knowledge Fallback: End-to-end Web Crypto mode works even without a live backend.
