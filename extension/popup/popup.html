Zero-Trace Architecture

This extension never stores plaintext secrets, encryption keys, or authentication tokens in browser storage.

Zero Plaintext Storage — AES-256-GCM encrypted at rest with 128-bit authentication tag
Atomic Self-Destruction — Secret purged from database immediately upon view or TTL expiry
Bot Guard — WhatsApp/Slack/Discord link preview crawlers are blocked from triggering burns
Offline ZK Fallback — End-to-end Web Crypto mode works without any backend server
